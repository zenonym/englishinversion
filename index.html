      Auxiliary verbs

      Look for an auxiliary before the main verb. In most inversion questions, move the first auxiliary before the subject.

      先搵 main verb 前面嘅 auxiliary。通常倒裝嗰陣，將第一個 auxiliary 搬到 subject 前面。

      GroupForms
      Beam, is, are, was, were, be, been, being
      Havehave, has, had
      Dodo, does, did
      Modalscan, could, may, might, must, shall, should, will, would

      If a simple present or past sentence has no auxiliary, add do, does, or did and use the base form of the main verb. When be is the main verb, it can move by itself.

      如果係 simple present 或 simple past 而冇 auxiliary，就加 do、does 或 did，再用 main verb 嘅 base form。如果 main verb 係 be，就可以直接搬 be。

      Starting words and phrases

      Use the starter to decide which pattern to try.

      睇吓句首用咗邊組字眼，就知應該用邊個 pattern。

      StarterWord order
      Never, Rarely, Seldom, Little, Not until, Under no circumstancesStarter → auxiliary → subject → main verb. Add do, does, or did if needed.
      Only then, Only after, Only when, Only byMove the whole Only phrase to the front, then put the auxiliary before the subject in the main clause.
      Not only … but also, Hardly or Scarcely … when, No sooner … thanPut the auxiliary before the subject in the first clause. Keep the second clause in its usual order.
      Neither, NorStarter → auxiliary → subject. The main verb is understood.
      Had, Were, ShouldDrop if and move Had, Were, or Should before the subject.
      Often, Twice, Many a timeFor optional formal inversion, move the starter to the front, then put the auxiliary before the subject.
      Here, ThereStarter → main verb → noun subject. A pronoun stays before the main verb.

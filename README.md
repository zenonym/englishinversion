# English Inversion

A matcha-themed practice game for English inversion (Never have I…, Only then did…, Had I known…, Here comes…).

- Seven practice sections with word tiles, animated examples and Cantonese notes
- A 20-question exam drawn from 117 questions, built with plain word tiles, with an answer review
- Accuracy by inversion type, so you can see what needs practice

Results save in your browser automatically. Use **Download my results** to keep a backup or move results to another device, and **Load results file** to restore them.

Open `index.html` in a browser, or enable GitHub Pages for this repository.
